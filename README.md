Interactive Blackjack Game

A fully functional, responsive web application of the classic card game Blackjack. 
This project was built to demonstrate complex game logic and dynamic DOM manipulation in vanilla JavaScript.

Live Demo: https://kristijandrazetic.github.io/BlackjackGame/

- State Tracking: Managing complex states such as standard deck arrays, player/dealer scores, active bets, and total budget.
- Event-Driven Architecture: Handling user inputs cleanly through structured DOM event listeners.
- Conditional Logic: Evaluating winning conditions (Bust, Blackjack, Dealer wins, Push) through strict conditional rules.

To run this project locally on your machine follow these simple steps:
  1. Download the project:
   - Click on the green "Code" button at the top right of this repository.
   - Select "Download ZIP" from the dropdown menu.
   - Extract the downloaded ".zip" file on your computer.

  2. Open in VS Code & Run Server:
   - Open Visual Studio Code.
   - Go to "File" > "Open Folder..." and select the extracted project folder.
   - Right-click on the "index.html" file and select "Open with Live Server" (or use the "Go Live" button in the bottom status bar) to launch the game with hot-reloading.
